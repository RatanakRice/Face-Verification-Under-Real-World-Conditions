# Results

Raw output files behind the report's numbers, copied in here so they can be
read without re-running the full pipeline. Generated by the scripts in
`src/` (see the main README's "Reproducing the report" table for which
script produces which file); these copies are static snapshots, not
regenerated automatically.

- `scorecard_bigger.txt` — Table I clean baseline, plus the superseded
  milder occlusion pilot (block_15_30/block_30_30).
- `scorecard_lighting_corrected.txt` — Table I lighting degraded/corrected
  rows.
- `scorecard_occlusion40.txt` — Table I occlusion (40% box) degraded row.
- `scorecard_occlusion_fixed.txt` — Table I occlusion mirror-fill corrected
  row.
- `scorecard_mixdata.txt` — Table II mixed-collection gate test (single
  seed).
- `scorecard_quality_gate.txt` — the gate run on the 15 single-condition
  folders, first pass (has the since-fixed ">100% recovery" scoring bug
  described in Results and Analysis / Quality Gate — kept for reference,
  not used as a reported number).
- `scorecard_quality_gate_fair.txt` — the same run, re-scored on matched
  pairs with coverage reported (the fix for the bug above).
- `mcnemar_results.csv` — Table III, every McNemar comparison (all 30, full
  precision).
- `mixdata_variance.json` — the 8-seed re-run behind Fig. 2 and the Run
  Distributions section.
